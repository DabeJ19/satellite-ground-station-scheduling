max  Σr,a,t xr,a,t − ε Σr,a,t (t − er)·xr,a,t
s.t.  Σa,t xr,a,t ≤ 1 ∀r（每需求至多一次）
      Σr Σt ≤ τ < t+dr+ca xr,a,t ≤ 1 ∀a, ∀τ（限制 1＋2：天線＋校準）
